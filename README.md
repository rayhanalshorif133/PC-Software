# V-Editor (মোবাইল স্টাইল ডেস্কটপ ভিডিও এডিটর)

`demo.jpeg`-এর মতো মিনিমালিস্ট মোবাইল ভিডিও এডিটর UI দিয়ে তৈরি একটি পাওয়ারফুল ও মডার্ন ডেস্কটপ ভিডিও এডিটর সফটওয়্যার (.exe)।

---

## 🌟 প্রধান ফিচারসমূহ (Features)

1. **রিয়েল-টাইম ভিডিও প্রিভিউ ও প্লে/পজ (Play & Pause Button):**
   - প্রিভিউ স্ক্রিনের নিচে বাম পাশে বড় Play / Pause বাটন (`▶` / `⏸`) রয়েছে।
   - স্পেসবার (`Space`) চাপ দিয়ে অথবা সরাসরি ভিডিওর উপর ক্লিক করেও প্লে ও পজ করা যায়।
   - চলমান সময়ের সাথে সাথে লাইভ টাইমকোড ডিসপ্লে (`0:00 | 0:01`) দেখা যায়।

2. **মাঝখানের স্পেশাল ইন্ডিকেটর লাইন দিয়ে ভিডিও কাট/স্প্লিট (Cut & Split at Center Playhead Needle):**
   - `demo.jpeg`-এর মতো টাইমলাইনের ঠিক মাঝখানে (৫০% সেন্টারে) একটি ফিক্সড সাদা দাগ/নিডল (`|`) রয়েছে।
   - ভিডিও প্লে করার সময় বা হাত দিয়ে টাইমলাইন স্ক্রোল করার সময় এই দাগটির নিচে ভিডিওর ফ্রেম মুভ করে।
   - নিচের টুলবারের **`][ Cut`** বাটনে চাপ দিলে বা কিবোর্ডে `C` / `S` চাপলে ঠিক ওই দাগের পজিশনে ভিডিওটি দুই খণ্ডে কেটে (Split) যায়।

3. **আনডু ও রিডু সুবিধা (Full Undo & Redo History):**
   - এডিটরটিতে রয়েছে কমপ্লিট হিস্টোরি স্ট্যাক।
   - টাইমলাইনের উপরে আনডু (`↶`) এবং রিডু (`↷`) বাটন রয়েছে।
   - যেকোনো কাট, ট্রিম, স্পিড পরিবর্তন, ভলিউম পরিবর্তন বা ক্লিপ ডিলেট সহজে `Ctrl + Z` দিয়ে Undo এবং `Ctrl + Y` দিয়ে Redo করা যায়।

4. **ইয়েলো হ্যান্ডেল ট্রিমার (Yellow Handle Trimming):**
   - নির্বাচিত ক্লিপের চারপাশে `demo.jpeg`-এর মতোই উজ্জ্বল হলুদ বর্ডার এবং দুই পাশে ড্র্যাগ হ্যান্ডেল `[` এবং `]` রয়েছে।
   - হ্যান্ডেল টেনে ভিডিও ক্লিপের শুরু ও শেষের অপ্রয়োজনীয় অংশ ট্রিম (Trim) করা যায়।
   - ক্লিপের নিচে রিয়েল-টাইম ডিউরেশন ব্যাজ (যেমনঃ `1.5s`) প্রদর্শিত হয়।

5. **ভিডিও স্পিড ও ভলিউম কন্ট্রোল (Speed & Volume):**
   - **Speed (`⏱`):** স্লো-মোশন ও ফাস্ট-ফরওয়ার্ড (0.25x, 0.5x, 0.75x, 1.0x, 1.25x, 1.5x, 2.0x)।
   - **Volume (`🔊`):** যেকোনো ক্লিপের আওয়াজ ০% থেকে ২০০% বাড়ানো বা কমানোর স্লাইডার।
   - **Reverse (`🔄`):** ক্লিপ রিভার্স করার অপশন।
   - **Delete (`🗑️`):** অপ্রয়োজনীয় ক্লিপ টাইমলাইন থেকে মুছে ফেলার অপশন।

6. **ভিডিও সেভ এবং ফাইল পাথ সিলেক্টর (Save & Export with Destination Picker):**
   - উপরের ডানদিকের **`Save`** বাটনে ক্লিক করলে এক্সপোর্ট ডায়ালগ ওপেন হয়।
   - **"Browse..."** বাটনে ক্লিক করে আপনি কম্পিউটারের যেকোনো ফোল্ডার ও নিজের পছন্দের ফাইলনেম দিয়ে `.mp4` হিসেবে সেভ করতে পারবেন।
   - হাই-স্পিড FFmpeg ইন্টিগ্রেশন যার মাধ্যমে রিয়েল-টাইম পার্সেন্টেজ বার (০% থেকে ১০০%) দেখা যায়।
   - এক্সপোর্ট শেষ হলে সরাসরি **"Open Folder in Explorer"** এবং **"Play Exported Video"** বাটনে ক্লিক করে ফলাফল দেখতে পারবেন।

## ⌨️ কিবোর্ড শর্টকাট (Keyboard Shortcuts)

| বাটন | কাজ |
|---|---|
| `Space` | ভিডিও প্লে / পজ |
| `C` বা `S` | ঠিক মাঝখানের দাগ বরাবর কাট / স্প্লিট |
| `Ctrl + Z` | Undo (পূর্বের অবস্থায় ফিরে যাওয়া) |
| `Ctrl + Y` | Redo (পুনরায় কার্যকর করা) |
| `Delete` / `Backspace` | সিলেক্টেড ক্লিপ ডিলেট |
| `Ctrl + S` | সেভ / এক্সপোর্ট ডায়ালগ ওপেন |
| `Ctrl + O` | নতুন ভিডিও ফাইল ওপেন |
| `←` / `→` | ০.১ সেকেন্ড পেছনে / সামনে ফ্রেম স্টেপ |

## 🚀 যেভাবে চালাবেন (How to Run)

### অপশন ১: সরাসরি তৈরি হওয়া Executable (.exe) চালানো
`dist/V-Editor/` ফোল্ডারে থাকা **`V-Editor.exe`** ফাইলে ডাবল ক্লিক করলেই অ্যাপ্লিকেশনটি ওপেন হয়ে যাবে!

### অপশন ২: পাইথন দিয়ে সরাসরি চালানো
```bash
python app.py
```
