# 🎥 VideoFrame Pro - Video to Frames & Human Detection

একটি সম্পূর্ণ আধুনিক উইন্ডোজ ডেস্কটপ সফটওয়্যার (Windows Desktop Software / `.exe`), যা যেকোনো ভিডিও থেকে **Full FPS** ফ্রেম-বাই-ফ্রেম অ্যানালাইসিস করে মানুষের উপস্থিতি (Human/Person Detection) স্বয়ংক্রিয়ভাবে শনাক্ত করে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **ভিডিও আপলোড ও প্রিভিউ**:
   - MP4, MKV, AVI, MOV, WMV, FLV ইত্যাদি যেকোনো ফরম্যাটের ভিডিও সিলেক্ট করার সুবিধা।
   - ভিডিও রেজোলিউশন, ফ্রেম রেট (FPS), টোটাল ফ্রেম সংখ্যা, ডিউরেশন ও সাইজ প্রিভিউ।

2. **Full FPS ও Frame-by-Frame বিশ্লেষণ**:
   - ভিডিওটির প্রতিটি ফ্রেম (Full FPS) এক্সট্র্যাক্ট করে ইমেজ ফরম্যাটে কনভার্ট করা হয়।
   - অপশন রয়েছে: Full FPS (প্রতিটি ফ্রেম), Half FPS, অথবা Fast 1 FPS মোড।

3. **স্বয়ংক্রিয় মানুষ শনাক্তকরণ (Automated AI Person Detection)**:
   - লাইটওয়েট ও উচ্চ ক্ষমতাসম্পন্ন YOLOv5n AI মডেল দ্বারা প্রতিটি ফ্রেমে মানুষ শনাক্ত করা হয়।
   - সেনসিটিভিটি / কনফিডেন্স থ্রেশহোল্ড স্লাইডার (15% থেকে 85%) দিয়ে ইচ্ছেমতো নিখুঁত করা যায়।

4. **স্মার্ট ফিল্টারিং ও লুকানো ফ্রেমের আলাদা ট্যাব**:
   - **👤 Person Detected (মানুষ আছে)**: যেসব ফ্রেমে মানুষ আছে, সেগুলো ডিফল্টভাবে এখানে প্রদর্শিত হবে।
   - **⚪ Hidden / No Person (লুকানো ফ্রেম)**: যেগুলোতে মানুষ নেই সেগুলো আলাদা এই ট্যাবে জমা থাকবে, যাতে প্রয়োজন হলে দেখতে বা ডাউনলোড করতে পারেন।
   - **🎞️ All Frames (সকল ফ্রেম)**: সম্পূর্ণ সিকোয়েন্স দেখার আলাদা ট্যাব।

5. **মাল্টি-সিলেকশন ও ডাউনলোড সিস্টেম**:
   - প্রতিটি ইমেজের জন্য চেকবক্স এবং ক্লিক সিলেকশন।
   - **Select All Page**, **Select All Tab**, **Deselect All**, **Invert** বাটন।
   - ডিফল্টভাবে কম্পিউটারের **Downloads** ফোল্ডারে সেভ হবে (`C:\Users\<user>\Downloads\Frames_<video_name>`)।
   - যেকোনো সময় **Change Path** দিয়ে আপনার পছন্দের ফোল্ডার সিলেক্ট করতে পারবেন।
   - **Open Folder** বাটনে ক্লিক করে সরাসরি এক্সপ্লোরারে সেভ করা ফাইলগুলো ওপেন করা যাবে।

6. **হাই-রেজোলিউশন ইমেজ প্রিভিউ ও জুম**:
   - যেকোনো থাম্বনেইলে ক্লিক বা ডাবল ক্লিক করলে ফুল রেজোলিউশন পপআপ উইন্ডো ওপেন হবে।
   - কিবোর্ডের `Left` ও `Right` অ্যারো দিয়ে আগের বা পরের ফ্রেমে নেভিগেট করার সুবিধা।
   - মানুষ যে স্থানে শনাক্ত হয়েছে তার বাউন্ডিং বক্স (Bounding Box) অন/অফ করার সুবিধা।

## 🚀 কীভাবে সফটওয়্যার চালাবেন (How to Run)

আপনার জন্য সফটওয়্যারটির ৩টি সহজ উপায় রাখা হয়েছে:

### উপায় ১: সিঙ্গেল Standalone `.exe` ফাইল (সবচেয়ে সহজ)
সরাসরি ডাবল ক্লিক করে রান করুন:
```
dist\VideoFramePro_Standalone.exe
```

### উপায় ২: দ্রুত চালু হওয়া ফোল্ডার ভার্সন (Instant Launch)
প্রজেক্টের মূল ফোল্ডারে থাকা লঞ্চারে ডাবল ক্লিক করুন:
```
Launch_VideoFramePro.bat
```
অথবা রান করুন:
```
dist\VideoFramePro\VideoFramePro.exe
```

### উপায় ৩: পোর্টেবল জিপ ফাইল (Portable ZIP Package)
অন্য যেকোনো পিসিতে পেনড্রাইভে নিয়ে যাওয়ার জন্য জিপ ফাইলটি প্রস্তুত:
```
VideoFramePro_v1.0_Windows.zip
```
(আনজিপ করে সরাসরি `VideoFramePro.exe` চালু করলেই চলবে, কোনো পাইথন বা সফটওয়্যার ইনস্টল করার প্রয়োজন নেই)।
