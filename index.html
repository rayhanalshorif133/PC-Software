📖 Repository Guide & Branch Architecture

🌱 Keno Branch-Based System?

Ekta single repository te prottek software ke alada alada branch e rakhar subidha holo:

  • Zero Bloat: --single-branch use korle shudhu matro sei software er files download hobe, baki software gulo download hoye hard disk er space nosto korbe na.
  • Auto Checkout: Clone hoyei auto sei branch e active hoye thakbe, manual git checkout korar dorkar hobe na.
  • Easy Updates: Shob software ekta repository te organized thakbe!

➕ Notun Software Branch add korben kivabe?

Jodi apnar 6th ba notun kono software branch add korte hoy:

# 1. Notun branch toiri korun
git checkout --orphan my-new-software

# 2. Purano files muche notun software er files copy korun
git rm -rf .
# (Apnar software files ekhane paste korun)

# 3. Commit ebong Push korun
git add .
git commit -m "Add my-new-software"
git push origin my-new-software

# 4. software-data.js e notun entry add korun ebong main branch push korun!

💡 Tip: Repository root e thaka add-software.bat file run koreo automatic branch create korte parben!
